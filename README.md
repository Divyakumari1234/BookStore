# E-Books Store

A responsive e-books store built with React, Vite, and Tailwind CSS.

## Requirements

- Node.js 18 or newer
- npm

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Divyakumari1234/BookStore.git
   ```

2. Open the project directory:

   ```bash
   cd BookStore
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open this URL in the browser:

   ```text
   http://127.0.0.1:5173
   ```

## Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Main Features

- Browse e-books by category
- Add and remove books from the cart
- Demo checkout with email validation
- Purchased books library
- Purchase history and reader notes
- Responsive desktop and mobile layout
